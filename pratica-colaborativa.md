# Nosso primeiro trabalho colaborativo no GitHub

## Breve descrição da atividade:
 -- Pesquisar o básico do GitHub, testar o compartilhamento de arquivos e produzir uma cartilha digital ou um minicurso para ensinar uma pessoa iniciante. --

## Dica do Tarsis:
  -- Seja sempre mente aberta para o aprendizado! --

## Dica do Derik:
 -- Não use o GitHub como um "Pen Drive": Explique que repositórios sem documentação não têm valor para recrutadores. --

## Nova dica:
 -- Commit: É o "salvar o jogo". Toda vez que você termina um pedaço do trabalho, você dá um commit com um aviso do que mudou. --

## Registro dos testes
- Todos conseguiram acessar e editar? Sim, todos conseguimos.
- Como identificaram os autores? Pelo nome ou foto no Commit.
- O que mudou após o merge? A adição da nova dica como teste para o projeto.

## Revisão com Pull Request
- Branch criada: `melhoria-guia`
- Alteração proposta: A adição da nova dica no projeto.
- Comentário do revisor: "Adição da nova dica"
- Resultado do merge: Sucesso, a branch melhoria-guia foi implementada na branch main com sucesso.
