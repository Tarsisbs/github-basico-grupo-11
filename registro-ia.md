# Registro do uso da Inteligência Artificial

## Ferramenta utilizada
ChatGPT (OpenAI).

## Prompt 1
"Explique para uma pessoa iniciante o que são Git e GitHub e diferencie repositório, commit, branch, pull request e merge, com exemplos simples."

## Prompt 2
"Ajude a organizar um guia introdutório sobre GitHub pelo navegador, incluindo criação de repositório, README, compartilhamento com colaboradores e cuidados ao publicar arquivos."

## Como fizemos a verificação
Conferimos se as informações são válidas tanto com o nosso conhecimento quanto com testes práticos no próprio GitHub para validação de tudo.
